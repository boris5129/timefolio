# 핵심 시간 규칙

- 시간 구간은 [시작, 종료)이고 분 단위 정수로 계산한다. 자정 통계는 해당 날짜 경계로 자른다. 계획과 실제의 합집합을 각각 구한다. 미기록 시간은 날짜 길이에서 실제 합집합을 뺀다. 남은 계획 가능 시간은 날짜 길이에서 계획과 실제를 합친 합집합을 뺀다.
- 활동 축소는 사용자 확인과 실제 기록이 필요하다. 사용자가 0분을 명시적으로 확인할 수 있게 한다. 같은 비교 활동의 별도 수행 시간을 합산한 뒤 max(0, 기준 − 실제)를 후보로 계산한다.
- 중첩은 주·보조 활동 교집합이다. 명시적으로 연결된 기존 별도 계획과 사용자 확인 분량이 있어야 절약을 인정한다. 인정량은 중첩 길이, 별도로 소비되지 않은 기준 시간, 확인 분량의 최솟값이다.
- 기준 활동 날짜별 분량에서 별도 실제 소비와 이미 인정된 축소·중첩 분량을 빼고, 동일 주 활동에서 이미 청구된 중첩 구간도 제외한다. 하나의 사용자 트랜잭션에서 잠금, 검증, 반영을 수행한다. 실제 기록 수정 등으로 배분 한도를 위반하면 관련 배분 조정이 필요하다는 충돌 오류를 반환한다.
- 재투자 실제 배분은 해당 날짜의 확인된 확보 근거와 실제 활동을 참조한다. 근거별 잔액과 실제 활동 분량을 각각 한도로 삼는다. 사용하지 않은 분량은 다음 날 가용량에 포함하지 않는다. 목표 상태는 사용자가 변경한다.
- 추천은 제외·보류·완료 항목 및 최소 시간 미충족 후보를 걸러낸다. 선택한 추천 유형, 우선순위, 임박한 기한, 남은 목표 시간, 선호도와 최근 사용 시간을 기준으로 정렬한다. ID로 동점을 해소한다. 남은 가용 분 안에서 배분하고 선택 이유를 표시한다. 적용 전 사용자가 편집한다.
- 시뮬레이션은 실제 달력 날짜를 열거한다. 요일과 적용 구간을 적용한 뒤 기준 분량의 중복을 제거하고 실천율을 적용한다. 예상 결과는 실제 기록과 별도로 저장한다.
