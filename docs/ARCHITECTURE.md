# 현재 아키텍처

`web/index.html`은 앱의 구조, `styles.css`는 반응형 레이아웃, `app.js`는 UI와 이벤트, `ledger.js`는 입력 검증·시간 계산·저장을 담당합니다. 외부 런타임 라이브러리를 로드하지 않습니다. Node.js 내장 HTTP 서버는 루프백 주소에서 허용된 정적 파일만 제공합니다.

저장 키는 `timefolio.ledger.v1`입니다. 카테고리와 활동을 하나의 버전 있는 문서로 저장합니다. 사용자 입력을 DOM의 텍스트로 넣습니다. 달력 날짜와 분 정밀도 입력은 Asia/Seoul의 민간 시각으로 표시하며, 일별 계산은 날짜 경계에 맞춰 잘라 합집합을 구합니다.

계정, 동기화 및 여러 사용자 공유가 필요해지면 저장 인터페이스의 구현을 API로 교체하는 방안을 검토합니다. 마스터 프롬프트는 최초 요구사항의 기록입니다. 현재 기술 경로는 DECISIONS.md를 따릅니다.
