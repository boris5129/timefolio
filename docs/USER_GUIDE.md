# Timefolio 사용 안내

PowerShell에서 `powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1`을 실행하고 http://127.0.0.1:4173을 엽니다.

1. 대시보드에서 **활동 추가**를 누릅니다. 09:00–10:30의 실제 활동을 저장하면 실제 기록 시간에 1시간 30분이 표시됩니다.
2. 활동 옆의 **수정**과 **삭제** 버튼을 사용합니다. 종료 날짜가 다음 날인 기록은 두 날짜의 타임라인에서 각각 해당 분량만 표시됩니다.
3. **시간 가계부**에서 최근 활동을 빠르게 등록하거나 전날 활동을 계획으로 복사합니다.
4. **카테고리**에서 이름과 색상, 아이콘을 관리합니다.

기록은 브라우저 프로필과 접속 주소에 연결됩니다. 같은 브라우저에서 항상 같은 주소로 접속하세요. 브라우저 사이트 데이터 삭제 시 기록도 지워집니다. 휴대전화와 PC 사이의 기록 공유에는 추후 동기화 기능이 필요합니다.

자동 검증은 `powershell -ExecutionPolicy Bypass -File .\scripts\verify.ps1`로 실행합니다.

프로젝트 폴더의 Timefolio.bat를 더블클릭하면 서버를 시작하고 Chrome에서 엽니다.

## 실제 활동, 계획, 반복 저장

- **실제 활동 추가**는 실제 기록을, **계획 추가**는 예정된 활동을 저장합니다.
- **반복 저장**을 열고 조회 날짜를 확인합니다. 시작 09:00, 종료 13:00, 첫 활동 수업 50분, 두 번째 활동 쉬는 시간 10분을 입력하면 각 활동이 네 번씩 저장됩니다. 실제 또는 계획을 선택할 수 있습니다.
- 마지막 활동은 지정한 종료 시각에 맞춰 줄어듭니다. 같은 이름·카테고리·종류·시각의 기록은 다시 만들지 않습니다. 저장한 기록은 타임라인에서 개별적으로 수정하거나 삭제할 수 있습니다.

## 원형 생활계획표와 기간별 활동

- **활동 등록**에서 날짜와 등록 종류를 고른 뒤 시계 숫자를 누르면 그 정각부터 시작하는 입력 창이 열립니다. 종료 시각은 기본 한 시간 뒤로 채워지며 직접 바꿀 수 있습니다.
- **오늘의 활동**의 원형 생활계획표는 바깥 고리에 실제 활동, 안쪽 고리에 계획을 표시합니다. 상세 목록은 전체·실제만·계획만으로 거를 수 있습니다. 제목을 누르면 수정 창이 열립니다.
- **주간 활동**과 **월간 활동**에서 기간을 이동하고 날짜를 눌러 상세 내역을 열 수 있습니다. 주간은 월요일에 시작합니다.
- **아낀 시간 기록**에는 직접 확인한 하루 절약 시간과 메모를 입력합니다. 주간·월간 화면에는 해당 날짜들의 합계가 표시됩니다.
- **활동 선택**으로 체크한 기록만 삭제하거나 **이 날짜 전체 삭제**로 해당 날짜에 걸친 실제 활동과 계획을 함께 삭제할 수 있습니다. 자정을 넘는 기록은 다른 날짜에서도 사라지며, 아낀 시간은 별도로 수정합니다.

## 요일·월간 반복 저장

**활동 등록 → 반복 저장 → 반복 주기**에서 매일, 평일(월~금), 매주 선택한 요일, 매월 같은 날짜를 고를 수 있습니다. 활동 등록 화면에서 고른 날짜부터 반복 종료 날짜까지 조건에 맞는 날에 계획을 저장합니다. 종료 날짜도 조건에 맞으면 포함합니다. 매월 31일을 선택한 경우 31일이 없는 달은 건너뜁니다. 생성된 계획은 각각 수정하거나 삭제할 수 있습니다.

## 무기한 반복과 공휴일 제외

반복 주기를 고르면 **무기한 반복**과 **한국 공휴일 제외**를 선택할 수 있습니다. 무기한 반복은 종료 날짜 없이 계속 표시됩니다. **활동 등록**에서 날짜를 고른 뒤 **무기한 반복 일정**의 **중단**을 누르면 해당 날짜부터 반복으로 표시되는 계획이 사라집니다. 이미 개별 수정해 저장한 기록은 활동 내역에서 관리합니다.

한국 공휴일 제외는 앱에 포함된 2026~2027년 한국 공휴일 및 대체공휴일을 사용하며, 일반 토요일·일요일은 반복 요일 설정으로 조절합니다. 다른 연도에는 공휴일 제외가 적용되지 않습니다.

- [2026년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?year=2026)
- [2027년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027)
- [2027년 월력요항 및 2026년 공휴일 변경 안내](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431)

## 카테고리별 시간 예산

**오늘의 활동 → 카테고리별 시간 예산**에서 선택한 날짜의 실제 사용 시간과 비교 기준을 봅니다. **목표 설정 → 카테고리 수정 → 하루 목표 (분)**에서 카테고리별 목표를 지정합니다. 예를 들어 2시간은 120분입니다. 목표가 비어 있으면 해당 날짜의 계획 시간을 비교 기준으로 사용합니다. 같은 카테고리 안에서 겹치는 실제 활동은 한 번만 합산합니다.

## 활동 중첩과 하루 돌아보기

같은 날짜에 이름 또는 카테고리가 다른 실제 활동이 겹치면 겹친 시간을 자동으로 집계합니다. 겹쳐 수행한 활동과 이름·카테고리가 같은 별도 계획을 대체한 경우 **대체 확인**으로 절약을 인정할 수 있습니다. 현재 한 날짜에 계획 하나를 확인할 수 있습니다. 같은 활동을 따로 수행한 부분은 절약에서 제외합니다. 중첩 절약과 직접 입력한 절약 시간은 중복 합산을 피하기 위해 별도로 표시합니다.

지난 날짜의 **하루 돌아보기**에서는 이름·카테고리·시각이 일치한 계획 이행 시간과 휴식·수면·취미 기록을 확인합니다. 카테고리 목표가 있으면 목표, 비어 있으면 해당 날짜의 계획을 비교 기준으로 사용합니다.

주간·월간 달력은 토요일을 파란색, 일요일과 공휴일을 빨간색으로 표시합니다. 공휴일 표시에는 앱의 2026~2027년 한국 공휴일 자료를 사용합니다.
