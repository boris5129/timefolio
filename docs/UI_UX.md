# 화면 설계

Phase 1 내비게이션은 대시보드, 시간 가계부, 카테고리 관리로 구성한다. 가입과 로그인은 하나의 진입 화면에 둔다. 대시보드는 선택일의 실제 기록, 예정 시간, 미기록 시간, 계획 가능 시간과 타임라인을 제공한다. 시간 가계부는 날짜 필터, 활동 추가·수정·삭제, 최근 활동, 전날 복사를 제공한다. 카테고리는 이름, 색상, 아이콘을 편집한다.

한국어 상태 안내, 레이블, 키보드 초점, 모바일에서 한 열로 흐르는 레이아웃을 사용한다. 실제와 계획은 문구와 색으로 구분한다. 이후에는 확보·중첩, 재투자·하고 싶은 일, 시뮬레이션·결산 및 설정을 추가한다.

## 현재 디자인 시스템

CSS 변수에 전체 배경, 콘텐츠, 텍스트, 파랑·녹색·보라·경고 색상과 모서리 및 좌우 여백을 정의합니다. 데스크톱은 왼쪽 탐색, 모바일은 두 줄 메뉴를 사용합니다. 홈은 오늘의 실제 사용량과 시간 자산을 먼저 표시한 뒤 실제·계획 타임라인과 활동 목록을 보여줍니다. 자세한 날짜별 활동에서는 원형 계획표와 카테고리 시간 예산을 계속 제공합니다. 로컬 저장소의 구조를 바꾸지 않고 URL 해시로 새로고침 시 화면을 복원합니다.
