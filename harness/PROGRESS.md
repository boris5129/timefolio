# 진행 상황

2026-11-24. 사용자 요청에 따라 순수 HTML·CSS·JavaScript로 전환했다. 활동 기록과 카테고리, 날짜별 대시보드, 브라우저 저장을 구현했다. 자동 검증을 통과해 사용자 확인을 기다린다. 서비스 주소는 http://127.0.0.1:4173이다.

이전 Java/MySQL 및 React 작업은 참고용이다. 브라우저 저장은 이전 DB를 불러오지 않는다. 이후 반복 일정, 확보·중첩, 재투자와 추천을 단계별로 구현한다.

같은 날짜 안에서 활동 묶음을 반복 저장하고 실제 활동과 계획을 별도 버튼으로 등록할 수 있다. 날짜를 넘나드는 반복 일정 규칙은 후속 범위다.

일별 원형 생활계획표, 시계에서 정각 등록, 주·월간 조회, 날짜별 수동 절약 기록, 선택 및 일별 전체 삭제를 구현했다. 사용자 사용성 확인 대기.

날짜 범위에 매일·평일·주 지정 요일·월 지정일 계획을 일괄 생성한다. 저장된 개별 계획을 수정할 수 있으며 반복 규칙 자체의 일괄 수정은 후속 범위다.

무기한 반복은 조회 시 계획을 계산하며 개별 수정·삭제와 날짜 기준 중단을 지원한다. 공휴일 제외용 달력은 2026~2027년 자료를 포함한다.

일일 카테고리별 실제 사용과 목표·계획 비교를 추가하고 밝은 파랑·보라·민트 테마를 적용했다.

전체 디자인을 흰색·회색·파랑 기반으로 재구성했다. 대시보드, 등록, 일·주·월간 활동, 시간 확보 기록, 카테고리, 설정, 주·월간 결산에 공통 레이아웃을 적용했다. 이전부터 미구현 상태인 중첩·재투자·개인 목표·위시리스트·시뮬레이션·계정은 안내 화면을 제공한다.

자동 중첩 감지와 별도 계획 대체 확인, 지난날 회고, 토요일·일요일·공휴일 표시를 추가했다. 중첩 절약은 날짜당 확인 계획 하나를 지원하며 직접 기록한 절약과 별도로 집계한다.
