# Timefolio

시간을 아끼는 것을 넘어, 원하는 삶에 투자하다.

현재 실행 대상은 [web](web/index.html)의 HTML, CSS, JavaScript 앱입니다. 활동과 카테고리는 같은 주소를 사용하는 브라우저 프로필의 localStorage에 저장합니다. Node.js는 정적 파일 제공과 테스트에 사용합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)을 열면 됩니다. 실행한 PowerShell 창에서 Ctrl+C를 누르면 종료됩니다. 프로젝트가 준비한 휴대용 Node.js 또는 PC에 설치된 Node.js 22 이상을 사용합니다.

- [사용 안내](docs/USER_GUIDE.md)
- [현재 구조](docs/ARCHITECTURE.md)
- [진행 상황](harness/PROGRESS.md)
- [원본 요구사항](docs/PROJECT_SPEC.md)
